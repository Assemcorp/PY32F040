================================================================================
                              Sample Description
================================================================================
Function Description:
This sample demonstrates the use of LCD and ADC. A potentiometer is connected to pin B1, which serves as the ADC input. As you turn the potentiometer, the corresponding ADC value is displayed on the LCD.
================================================================================
Test Environment:
Test Board: PY32F040_AssemCorp_DevKit 
MDK Version: 5.28  
IAR Version: 9.20  
GCC Version: GNU Arm Embedded Toolchain 10.3-2021.10
================================================================================
Execution Steps:
1.Compile and flash the program to the development board.
2.Rotate the potentiometer connected to B1 and observe the ADC value on the LCD.
================================================================================

B1   -->  ADC input (potentiometer)
